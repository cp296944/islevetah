# 嶼地特寵醫院盤點系統

支援手機及電腦的共用庫存盤點系統。Python 3.10+ 標準函式庫與 SQLite，無需安裝第三方套件。

## 啟動（Windows PowerShell）

```powershell
$env:INVENTORY_PASSWORD = '請換成你的登入密碼'
python server.py
```

開啟 http://127.0.0.1:8000 ，使用設定的密碼登入。初次啟動沒有示範資料，請先新增商品。

供院內不同手機與電腦共用：

```powershell
python server.py --host 0.0.0.0 --port 8000
```

員工在同一院內網路開啟 `http://伺服器區網IP:8000`。Windows 防火牆需允許私人網路的 8000 連接埠；伺服器必須保持開機。此版為院內共用密碼登入，盤點人員自行填名，尚未提供個別帳號與管理員權限。若公開到網際網路，應使用正式 HTTPS 反向代理並加上登入限速，勿直接公開 Python HTTP 伺服器。

## 功能

- 總覽：最新實際盤點數量、日期、人員、每週預估耗用量、預計用盡日期。
- 紅字提醒：預估用盡日期距今不足 5 天、已過預估日期、實際盤點為零。
- 商品：品名、國際條碼（選填且唯一）、單位、分類、位置、備註、啟用或停用。
- 盤點：批次填寫數量、姓名、實際時間及備註；未填商品略過，0 明確保存。
- 耗用量：按時間排序，以最近最多 6 段庫存持平或減少區間的總減少量 / 總天數估算。庫存增加整段排除，包括該段天數。
- 全部時間以台灣 UTC+8 為準。只有一筆紀錄或沒有有效區間不推估；平均耗用為零不推算用盡日期。
- CSV 匯出；盤點歷史保留，不提供刪除功能。

期間補貨但最後庫存仍減少，無法辨識，可能低估耗用；請用總覽的最後實際盤點數量人工判斷。預估用盡日期以最新盤點時間與數量為起點，非以今天為起點。

## 資料與備份

資料保存在 `data/inventory.db`，不會提交到 GitHub。停止伺服器後複製 `data` 資料夾即可備份，還原時放回同一路徑。可用 `INVENTORY_DB` 環境變數指定資料庫路徑。密碼只透過環境變數設定；每次重啟需重新登入。

已有紀錄的商品不應變更單位。盤點錯誤目前需由管理者處理資料庫；建議後續加入有稽核歷史的更正流程。

## 驗證

```powershell
python -m unittest discover -s tests -v
node --check public/app.js
```

## GitHub 與部署

GitHub 儲存程式碼，GitHub Pages 無法執行這套 Python / SQLite 共用後端。實際使用請啟動院內伺服器，或部署到支援 Python 且有持久磁碟的主機。
